# Student Performance Analysis & Dashboard

## 📌 Overview

This project analyzes student academic performance using Microsoft Excel.

The dataset contains 250 student records with marks across Science, English, History, and Maths. The project transforms raw student data into meaningful performance metrics, category-based analysis, and an interactive-style dashboard.

## 🎯 Objectives

- Analyze student academic performance
- Calculate total marks, average marks and percentages
- Categorize students based on performance
- Identify top and bottom performing students
- Compare performance across subjects, sections and gender
- Build a visual dashboard for academic performance monitoring
- Generate actionable insights from student data

## 🛠️ Tools & Techniques

- Microsoft Excel
- Excel Tables
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Design

## 🔍 Key Insights

- 250 students were analyzed.
- Overall average percentage was 51.18%.
- The overall pass rate was 52%.
- The highest recorded percentage was 90.25%.
- 120 students were categorized as At Risk.
- 4 students were categorized as Excellent.
- Maths had the highest average subject score at approximately 52.27%.
- Section C recorded the highest average percentage among the three sections at approximately 52.49%.
